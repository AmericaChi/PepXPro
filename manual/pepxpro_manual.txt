PepXPro Manual
=============
Modular framework for generating peptide-protein benchmark datasets from PDBbind.

REPOSITORY LAYOUT
-----------------
scrape_pdb_bind/   Download, filter, and prepare CIFs from PDBbind + external datasets.
gen_sample/        Filter, deduplicate, sample, and export datasets.
pepxpro_benchmark/ Curated versioned benchmark releases (v1/, v2/, …).
manual/            This file and tutorial.txt.

Environment:  conda activate pepxpro
              cd-hit required for --seq-id-receptor: conda install -c conda-forge -c bioconda cd-hit
              openpyxl optional, required for .xlsx external datasets: conda install -c conda-forge openpyxl


===========================================================================
PIPELINE: scrape_pdb_bind/
===========================================================================
Run steps sequentially from scrape_pdb_bind/scripts/:

  python 01_download.py
  python 02_filter.py
  python 03_summary.py
  python 04_distributions.py

Each script accepts --clean to remove its output files.

01_download.py FLAGS
--------------------
--index FILE      PDBbind index file (default: inputs/INDEX_general_PL.2020).
                  Use inputs/INDEX_general_PL.2020R1.lst for the re-processed v2020R1 index
                  (better quality structures, updated binding data, subset of v2020).
--temperature K   Fallback temperature in K for ΔG = RT ln(Kd/Ki) when not reported in the
                  index notes (default: 300.0). Temperature is parsed automatically from
                  the index comment field when available.

INPUTS
------
inputs/INDEX_general_PL.2020        PDBbind flat-file index (manual download, requires registration)
inputs/INDEX_general_PL.2020R1.lst  Re-processed v2020R1 index (optional, see above)
pdb_cache/                          Raw assembly CIFs (generated by step 1)

OUTPUTS
-------
outputs/peptide_entries.tsv    pdb_id, n_mer, year, binding_type, dG_kcal, dG_approx,
                               step1_reject, resolution, temperature
outputs/filtered_systems.tsv   Per-entry filter results + full metadata (see columns below)
outputs/summary.tsv            Final merged table — all metadata, sorted strong→weak by dG
outputs/plots/
  summary_distributions.png   Box plot grid for all numeric columns
  summary_statistics.tsv      N, mean, std, min, Q1, median, Q3, max per column
fixed_cif/                     Fixed CIFs: AMBER14-compatible, missing residues filled
logs/                          Per-step log files

filtered_systems.tsv columns (accepted rows):
  pdb_id, n_mer, accepted, assembly_num,
  peptide_chain, peptide_length, peptide_added, peptide_seq,
  peptide_ss (_struct_conf deposited), peptide_ss_dssp (Biopython DSSP),
  receptor_chains, receptor_length, receptor_added, receptor_seq,
  receptor_ss (_struct_conf deposited), receptor_ss_dssp (Biopython DSSP),
  receptor_description, receptor_func_class,
  resolution, reject_reason

summary.tsv columns:
  pdb_id, receptor, peptide, dG_kcal_mol, binding_type, resolution, year, temperature,
  peptide_added, peptide_seq, peptide_ss, peptide_ss_dssp,
  peptide_pct_helix, peptide_pct_beta, peptide_pct_coil,
  receptor_added, receptor_seq, receptor_ss, receptor_ss_dssp,
  receptor_pct_helix, receptor_pct_beta, receptor_pct_coil,
  receptor_description, receptor_func_class

receptor_func_class values:
  enzyme, chaperone, structural, signal, regulatory, peptide-binding, other


===========================================================================
SCRIPT: 05_external.py  (optional — integrate external datasets)
===========================================================================
Normalizes an external affinity dataset (xlsx/tsv/csv), downloads CIFs,
runs filter + summary, and merges with the PDBbind summary.

  python 05_external.py --input inputs/external/PEPBI.xlsx --name pepbi
  python 05_external.py --merge-only     # re-merge all existing external summaries

FLAGS
-----
--input FILE        External dataset file (xlsx, tsv, csv).
--name NAME         Short identifier (used to name output files). Default: input filename stem.
--no-download       Skip CIF download.
--no-filter         Skip 02_filter.py step.
--no-summary        Skip 03_summary.py step.
--no-merge          Skip merge with PDBbind summary.tsv.
--merge-only        Re-run merge of all existing summary_*.tsv files. No --input required.
--force-colmap      Ignore saved column map and re-detect interactively.
--temperature K     Fallback temperature in K for ΔG = RT ln(Kd/Ki) when not present in
                    the dataset (default: 300.0). Uses the dataset temperature column
                    when available.

COLUMN MAPPING
--------------
Auto-detected from FIELD_ALIASES on first run; saved to inputs/external/<name>_colmap.json.
Prompts interactively for unrecognized fields. Subsequent runs load the saved map.
Recognized fields: pdb_id, dg_exp, dg_calc, kd, ki, n_mer, peptide_seq,
                   resolution, year, binding_type, temperature.

OUTPUTS
-------
outputs/peptide_entries_<name>.tsv
outputs/filtered_systems_<name>.tsv
outputs/summary_<name>.tsv
outputs/summary_merged.tsv    PDBbind + all external sources combined

NOTES
-----
- Temperature: uses T from the dataset row (K) for dG = RT ln(Kd/Ki); falls back to --temperature (default 300 K).
- Year/resolution: filled from CIF (_citation.year) then RCSB REST API if CIF lacks data.
- Deduplication: PDB IDs already in PDBbind outputs are skipped.
- Multiple external datasets accumulate automatically; --merge-only rebuilds the union.


===========================================================================
PIPELINE: gen_sample/
===========================================================================
Run from gen_sample/scripts/. Reads from scrape_pdb_bind/outputs/.
Writes to gen_sample/outputs/run_XX/.

  python 01_gen_sample.py --sample 20
  python 01_gen_sample.py --dry-run
  python 02_benchmark_sampling.py
  python 03_compare_runs.py --run run_01
  python 05_view_sample.py --run 1

OUTPUT (gen_sample/outputs/run_XX/)
------------------------------------
sample.tsv                 Selected entries.
run_config.json            All parameters used (fully reproducible).
pool_quality.tsv           Entries after quality filters.
pool_redundancy.tsv        Entries after redundancy filters.
peptide_sequences.fasta    (only with --export-fasta)
receptor_sequences.fasta   (only with --export-fasta)
cif/  or  pdb/             Structure files (only with --link-cifs / --copy-cifs / --protonate)
plots/run_comparison.png   (only with 03_compare_runs.py)

MODES  (one required)
----------------------
--sample N      Sample N entries.
--no-sample     Take the full filtered pool.
--dry-run       Print pool statistics only. No output written.
--pick PDB_ID   Extract one system by PDB ID. Bypasses all filters.

INPUT
-----
--summary-tsv FILE   Path to summary TSV. Default: scrape_pdb_bind/outputs/summary.tsv.
                     Use summary_merged.tsv to include external datasets.

SAMPLING  (only with --sample)
-------------------------------
--sampling METHOD    stratified (default), kennard-stone, kde, isolation-forest, cluster.
--dims DIM [DIM ...] Sampling dimensions. Default: dg pep_len.
                     Available: dg, pep_len, rec_len, n_rec_chains, ss_class, func_class.
--seed N             Random seed for reproducibility.

QUALITY FILTERS  (all optional)
---------------------------------
--single-chain               Keep only single receptor-chain entries. Default: OFF.
--min/max-receptor N         Receptor residue count bounds.
--min/max-peptide N          Peptide residue count bounds.
--min/max-dg F               Binding affinity range (kcal/mol).
--min/max-year N             Deposition year range.
--min/max-resolution F       Crystallographic resolution range (Å). Excludes NMR if set.
--exclude-nmr                Remove entries with no numeric resolution.
--binding-type kd|ki|both    Measurement type. Default: both.
--max-added N                Max residues PDBFixer added to peptide.
--max-receptor-added N       Max residues PDBFixer added to receptor.
--exclude FILE               Blacklist file: one pdb_id per line.

REDUNDANCY FILTERS  (all optional; quality → seq → structural → sampling)
--------------------------------------------------------------------------
--seq-id-receptor PRESET     CD-HIT receptor clustering.
                             Presets: strict (40%), medium (50%), lenient (70%), custom.
                             Minimum supported threshold: 40% (CD-HIT limitation).
--seq-id-receptor-threshold F  Custom identity threshold (must be >= 0.40).
--seq-id-peptide PRESET      Biopython pairwise peptide clustering.
                             Presets: strict (70%), medium (80%), lenient (90%), custom.
--seq-id-peptide-threshold F   Custom identity threshold.
--tm-score-receptor F        Receptor TM-score threshold (0.5 = same fold).
                             Parallelized across CPU cores. Requires tmtools.

EXPORT  (all optional; combinable)
------------------------------------
--link-cifs           Symlink CIFs into run_XX/cif/.
--copy-cifs           Copy CIFs into run_XX/cif/.
--format cif|pdb      Output structure format. Default: cif.
--protonate           Add missing hydrogens at given pH. Implies --copy-cifs.
--ph F                pH for protonation. Default: 7.0.
--export-fasta        Write FASTA files for peptide and receptor sequences.
--full-metadata       Write all summary.tsv columns to sample.tsv (default: compact).
--no-save-pools       Skip saving pool_quality.tsv and pool_redundancy.tsv.

USAGE EXAMPLES
--------------
python 01_gen_sample.py --sample 20
python 01_gen_sample.py --sample 20 --sampling kennard-stone --seed 42
python 01_gen_sample.py --sample 20 --sampling kde
python 01_gen_sample.py --sample 20 --sampling cluster --dims dg pep_len rec_len
python 01_gen_sample.py --sample 20 --dims func_class dg
python 01_gen_sample.py --sample 20 --min-year 2010 --max-resolution 2.5
python 01_gen_sample.py --sample 20 --seq-id-receptor medium --seq-id-peptide strict
python 01_gen_sample.py --sample 20 --tm-score-receptor 0.5 --max-peptide 4
python 01_gen_sample.py --sample 20 --link-cifs
python 01_gen_sample.py --sample 20 --copy-cifs --format pdb
python 01_gen_sample.py --sample 20 --protonate --ph 7.4 --format pdb
python 01_gen_sample.py --sample 20 --full-metadata --summary-tsv ../../scrape_pdb_bind/outputs/summary_merged.tsv
python 01_gen_sample.py --no-sample --export-fasta
python 01_gen_sample.py --dry-run --max-peptide 15 --binding-type kd
python 01_gen_sample.py --pick 1abc
python 01_gen_sample.py --pick 1abc --protonate --format pdb


===========================================================================
SCRIPT: 03_compare_runs.py
===========================================================================
Distribution plots for a single run: quality pool → redundancy pool → sample.
Output: run_XX/plots/run_comparison[_dimx_dimy].png

FLAGS
-----
--run RUN_DIR       Run directory name inside gen_sample/outputs/, e.g. run_01.
--run-dir PATH      Full path to any directory with pool_quality.tsv,
                    pool_redundancy.tsv, and sample.tsv (e.g. pepxpro_benchmark/v1/).
--dims DIM_X DIM_Y  Override dims from run_config.json (e.g. --dims dg ss_class).
                    Output filename includes dims: run_comparison_dg_ss_class.png
--output FILE       Override output path.

USAGE EXAMPLES
--------------
python 03_compare_runs.py --run run_01
python 03_compare_runs.py --run run_01 --dims dg ss_class
python 03_compare_runs.py --run run_01 --dims dg func_class
python 03_compare_runs.py --run-dir ../../pepxpro_benchmark/v1 --dims dg ss_class


===========================================================================
SCRIPT: 02_benchmark_sampling.py
===========================================================================
Compares all 5 sampling methods on the same filtered pool.
Output: gen_sample/outputs/plots/sampling_benchmark.png

FLAGS
-----
--n N              Entries per method. Default: 20.
--seed N           Random seed.
--dims DIM [DIM]   Plot axes. Default: dg pep_len.

USAGE EXAMPLES
--------------
python 02_benchmark_sampling.py --n 30 --seed 42
python 02_benchmark_sampling.py --dims rec_len pep_len


===========================================================================
SCRIPT: 05_view_sample.py
===========================================================================
Browse run structures in PyMOL. Left/right arrows to navigate.
Structures shown in dG order (tightest first).

FLAGS
-----
--run N         Run number. Default: latest run.
--cif-dir DIR   Override CIF directory (default: run_XX/cif/ then scrape fixed_cif/).

USAGE EXAMPLES
--------------
python 05_view_sample.py
python 05_view_sample.py --run 3
python 05_view_sample.py --run 8 --cif-dir cif


===========================================================================
PIPELINE: pepxpro_benchmark/
===========================================================================
Curated, versioned benchmark releases. Each version is a self-contained
directory (v1/, v2/, …) with structures, sequences, metadata, and plots.

No run_XX is created in gen_sample/outputs/.

Intended workflow:
  1. Tune parameters using gen_sample/01_gen_sample.py (--dry-run, --sample)
  2. Once parameters are final, run the benchmark script for a reproducible release.

  conda activate pepxpro
  cd pepxpro_benchmark/scripts
  python 01_make_benchmark.py              # creates pepxpro_benchmark/v1/
  python 01_make_benchmark.py --dry-run    # pool stats only, nothing written
  python 01_make_benchmark.py --version v2 # explicit version label

OUTPUT (pepxpro_benchmark/vN/)
------------------------------
sample.tsv                 Selected entries, full metadata.
run_config.json            All parameters (filters, sampling, seed, sources).
pool_quality.tsv           Entries after quality filters.
pool_redundancy.tsv        Entries after redundancy filters.
cif/                       Fixed CIFs (AMBER14-compatible, copied).
pdb/                       PDB conversions (via PDBFixer/OpenMM).
sequences/
  peptide_sequences.fasta
  receptor_sequences.fasta
plots/
  summary_distributions.png          Box plots for all numeric columns.
  run_comparison_dg_ss_class.png     Filtering pipeline: dG × SS class.
  run_comparison_dg_func_class.png   Filtering pipeline: dG × functional class.
README.txt                 Provenance, pipeline counts, selection criteria.

BENCHMARK PARAMETERS (edit BENCHMARK_PARAMS in 01_make_benchmark.py)
---------------------------------------------------------------------
Current v1 configuration:
  --sample 89  --single-chain
  --seq-id-receptor strict (40%)  --seq-id-peptide strict (70%)
  --tm-score-receptor 0.5
  --sampling kennard-stone  --dims dg ss_class func_class
  --summary-tsv summary_merged.tsv  --seed 42

VISUALIZING A BENCHMARK VERSION
---------------------------------
Use 05_view_sample.py from gen_sample with --cif-dir pointing to the benchmark:
  cd gen_sample/scripts
  python 05_view_sample.py --run-dir ../../pepxpro_benchmark/v1 --cif-dir cif

(05_view_sample.py does not yet support --run-dir; use --cif-dir with any run
that shares the same sample.tsv, or run gen_sample once with --link-cifs
pointing to the same sample.)


===========================================================================
NOTES
===========================================================================
- Run scrape_pdb_bind scripts from scrape_pdb_bind/scripts/.
- Run gen_sample scripts from gen_sample/scripts/.
- Conda environment: conda activate pepxpro
- run_config.json records every parameter for full reproducibility.
- Large output files (CIFs, PDBs, plots) are not tracked by git.
- --protonate does not strip existing hydrogens; fills missing ones only.
- SS annotations: peptide_ss/_receptor_ss from deposited _struct_conf (may be NA for NMR);
  peptide_ss_dssp/receptor_ss_dssp from mkdssp (covers all experimental methods).
- peptide_ss_class values: helix (≥70% H), beta (≥50% E), mixed (≥20% H and ≥20% E),
  partial-helix (≥30% H), coil (>50% C), other (ambiguous partial), NA.
- DSSP requires mkdssp binary and CCD dictionary files in:
    $CONDA_PREFIX/var/cache/libcifpp/
  (components.cif, mmcif_pdbx.dic, mmcif_ma.dic — downloaded once at setup)
