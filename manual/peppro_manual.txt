PepPro Manual
=============
Modular framework for generating peptide-protein benchmark datasets from PDBbind.

REPOSITORY LAYOUT
-----------------
scrape_pdb_bind/   Modular pipeline: download, filter, and prepare CIFs from PDBbind.
gen_sample/        Filtering, sampling, and export pipeline.
manual/            This file.

===========================================================================
PIPELINE: scrape_pdb_bind/
===========================================================================
Run steps sequentially from scrape_pdb_bind/scripts/:

  python -u 01_download.py   2>&1 | tee ../logs/01_download.log
  python -u 02_filter.py     2>&1 | tee ../logs/02_filter.log
  python    03_summary.py
  python    04_distributions.py

Each script accepts --clean to remove its output files.

INPUTS
------
inputs/INDEX_general_PL.2020   PDBbind flat-file index (manual download, requires registration)
pdb_cache/                     Raw assembly CIFs (generated by step 1)

OUTPUTS
-------
outputs/peptide_entries.tsv    pdb_id, n_mer, year, binding_type, dG_kcal, dG_approx, step1_reject
outputs/filtered_systems.tsv   Per-entry filter results + full metadata (see columns below)
outputs/summary.tsv            Final merged table — all metadata, sorted strong→weak by dG
outputs/plots/
  summary_distributions.png   Box plot grid for all numeric columns
  summary_statistics.tsv      N, mean, std, min, Q1, median, Q3, max per numeric column
fixed_cif/                     Fixed CIFs: AMBER14-compatible, missing residues filled
logs/                          Per-step log files

filtered_systems.tsv columns (accepted rows):
  pdb_id, n_mer, accepted, assembly_num,
  peptide_chain, peptide_length, peptide_added, peptide_seq,
  peptide_ss (_struct_conf deposited), peptide_ss_dssp (Biopython DSSP),
  receptor_chains, receptor_length, receptor_added, receptor_seq,
  receptor_ss (_struct_conf deposited), receptor_ss_dssp (Biopython DSSP),
  resolution, reject_reason

summary.tsv columns:
  pdb_id, receptor, peptide, dG_kcal_mol, binding_type, resolution, year,
  peptide_added, peptide_seq, peptide_ss, peptide_ss_dssp,
  peptide_pct_helix, peptide_pct_beta, peptide_pct_coil,
  receptor_added, receptor_seq, receptor_ss, receptor_ss_dssp,
  receptor_pct_helix, receptor_pct_beta, receptor_pct_coil


===========================================================================
SCRIPT: gen_sample/scripts/gen_sample.py
===========================================================================
Reads from scrape_pdb_bind/outputs/. Writes to gen_sample/outputs/run_XX/.

INPUT FILES (from scrape_pdb_bind/outputs/)
--------------------------------------------
summary.tsv            Main input. Columns: pdb_id, receptor, peptide, dG_kcal_mol, binding_type, ...
                       receptor format: "AB:440"  (chain IDs + total residue count)
                       peptide  format: "C:8"     (chain ID  + residue count)
filtered_systems.tsv   Required for --max-added and --max-receptor-added.
fixed_cif/             Source CIF structures.

OUTPUT (gen_sample/outputs/run_XX/)
------------------------------------
sample.tsv             Selected entries.
run_config.json        All parameters used: mode, filters, sampling method, seed, paths.
pool_quality.tsv           Entries after quality filters (before redundancy). Saved by default.
pool_redundancy.tsv        Entries after redundancy filters (before sampling). Saved by default.
peptide_sequences.fasta    Peptide sequences in FASTA format (only with --export-fasta).
receptor_sequences.fasta   Receptor sequences in FASTA format (only with --export-fasta).
cif/  or  pdb/             Structure files (only if --link-cifs, --copy-cifs, or --protonate).
plots/
  run_comparison.png       Filtering + sampling distribution plot (03_compare_runs.py).

OUTPUT OPTIONS  (all optional)
-------------------------------
--no-save-pools        Do not save pool_quality.tsv and pool_redundancy.tsv (saved by default).

MODES  (mutually exclusive, one required)
------------------------------------------
--sample N             Sample N entries from the filtered pool.
--no-sample            Take the full filtered pool without sampling.
--dry-run              Print pool statistics after filtering. No output written.
--pick PDB_ID          Extract one system by PDB ID. Bypasses all filters and sampling.

SAMPLING  (only with --sample)
-------------------------------
--sampling METHOD      Sampling algorithm. Choices:
                         stratified       Quantile-bin grid. 1D: n bins; 2D: 6x6 grid. Default.
                         kennard-stone    Maximizes minimum pairwise Euclidean distance (N-D).
                         kde              Inverse KDE density sampling (always 1D).
                         isolation-forest Weights by isolation forest anomaly score (N-D).
                                          Requires scikit-learn.
                         cluster          K-means (k=n); selects entry nearest each centroid (N-D).
                                          Requires scikit-learn.
                       Plot labels include effective dimensionality: stratified-2D, kde-1D, etc.
--dims DIM [DIM ...]   Dimensions for sampling. Available: dg, pep_len, rec_len, n_rec_chains.
                       Default: dg pep_len. KDE always uses only the first dim.
--seed N               Random seed for reproducibility (affects stratified, kde, cluster).

FILTERS  (applied before sampling; all optional)
-------------------------------------------------
--single-chain         Keep only single receptor-chain entries. Default: ON.
--no-single-chain      Disable single-chain filter.
--min-receptor N       Minimum receptor residue count.
--max-receptor N       Maximum receptor residue count.
--min-peptide N        Minimum peptide residue count.
--max-peptide N        Maximum peptide residue count.
--min-dg F             Minimum dG in kcal/mol  (e.g. --min-dg -20).
--max-dg F             Maximum dG in kcal/mol  (e.g. --max-dg -5).
--binding-type TYPE    Filter by measurement type. Choices: kd  ki  both. Default: both.
--max-added N          Max residues PDBFixer added to peptide. Requires filtered_systems.tsv.
--max-receptor-added N Max residues PDBFixer added to receptor. Requires filtered_systems.tsv.
--exclude FILE         Path to a file with one pdb_id per line to exclude from pool.

REDUNDANCY  (applied after quality filters, before sampling; all optional)
---------------------------------------------------------------------------
--seq-id-receptor PRESET    Receptor sequence redundancy via CD-HIT. Presets:
                              strict  = 30% identity
                              medium  = 50% identity
                              lenient = 70% identity
                              custom  = use --seq-id-receptor-threshold
                            Requires receptor_seq column in summary.tsv.
--seq-id-receptor-threshold F  Identity threshold for custom preset (e.g. 0.40).
--seq-id-peptide PRESET     Peptide sequence redundancy via Biopython pairwise
                            (Needleman-Wunsch, BLOSUM62). Presets:
                              strict  = 70% identity
                              medium  = 80% identity
                              lenient = 90% identity
                              custom  = use --seq-id-peptide-threshold
                            Requires peptide_seq column in summary.tsv.
--seq-id-peptide-threshold F   Identity threshold for custom preset (e.g. 0.80).

Note: when both --seq-id-receptor and --seq-id-peptide are active, receptor
filtering runs first (CD-HIT), then peptide filtering (Biopython) on the result.

STRUCTURAL REDUNDANCY  (applied after seq redundancy; requires fixed_cif/)
---------------------------------------------------------------------------
--tm-score-receptor F  Receptor TM-score threshold (e.g. 0.5). Pairs with
                       TM-score >= threshold are redundant. 0.5 = same fold.
                       Requires tmtools: pip install tmtools
--irmsd F              Interface RMSD threshold in Å (e.g. 2.0). Applied after
                       --tm-score-receptor. Interface defined as receptor CA
                       within --irmsd-dist Å of any peptide atom. Pairs with
                       iRMSD < threshold are redundant.
--irmsd-dist F         Distance in Å to define interface (default: 4.0).

Note: --irmsd is designed to run after --tm-score-receptor. Using --irmsd alone
(without --tm-score-receptor) will produce a warning.

EXPORT  (all optional; can be combined)
----------------------------------------
--link-cifs            Symlink structure files into run_XX/cif/ (or pdb/).
--copy-cifs            Copy structure files into run_XX/cif/ (or pdb/).
--protonate            Add missing hydrogens and protonate at given pH. Implies file copy.
--ph F                 pH for protonation. Default: 7.0. Only used with --protonate.
--format FMT           Output structure format. Choices: cif  pdb. Default: cif.
--export-fasta         Write peptide_sequences.fasta and receptor_sequences.fasta to run_XX/.
                       Requires peptide_seq / receptor_seq columns in summary.tsv.
                       Use with Clustal Omega, MUSCLE, or any MSA tool.

USAGE EXAMPLES
--------------
python gen_sample.py --sample 20
python gen_sample.py --sample 20 --no-single-chain
python gen_sample.py --sample 20 --sampling kennard-stone --seed 42
python gen_sample.py --sample 20 --sampling kde
python gen_sample.py --sample 20 --sampling isolation-forest
python gen_sample.py --sample 20 --sampling cluster --seed 42
python gen_sample.py --sample 20 --dims dg
python gen_sample.py --sample 20 --sampling kennard-stone --dims dg rec_len
python gen_sample.py --sample 20 --min-peptide 5 --max-peptide 15 --max-receptor 300
python gen_sample.py --sample 20 --min-dg -15 --max-dg -6 --binding-type kd
python gen_sample.py --sample 20 --max-added 3 --max-receptor-added 10
python gen_sample.py --sample 20 --exclude bad_ids.txt
python gen_sample.py --sample 20 --link-cifs
python gen_sample.py --sample 20 --copy-cifs --format pdb
python gen_sample.py --sample 20 --protonate --ph 7.4 --format pdb
python gen_sample.py --no-sample --link-cifs
python gen_sample.py --dry-run --max-peptide 15 --binding-type kd
python gen_sample.py --pick 1abc
python gen_sample.py --pick 1abc --protonate --ph 6.5 --format pdb


===========================================================================
SCRIPT: gen_sample/scripts/03_compare_runs.py
===========================================================================
Plots the distribution of entries at each pipeline stage for a single run:
  quality pool → redundancy pool → sample
Requires pool_quality.tsv and pool_redundancy.tsv in the run directory
(saved by default by 01_gen_sample.py; use --no-save-pools to skip).

Output: run_XX/plots/run_comparison.png

FLAGS
-----
--run RUN_DIR   Run directory name (required), e.g. run_01.

USAGE EXAMPLES
--------------
python 03_compare_runs.py --run run_01


===========================================================================
SCRIPT: gen_sample/scripts/benchmark_sampling.py
===========================================================================
Compares all 5 sampling methods on the same filtered pool.
Produces a 1x5 scatter plot (dims[0] x dims[1]) per method.
Output: gen_sample/outputs/plots/sampling_benchmark.png

FLAGS
-----
--n N              Number of entries to sample per method. Default: 20.
--seed N           Random seed. Default: none.
--dims DIM [DIM]   Two dimensions for the plot axes. Default: dg pep_len.

USAGE EXAMPLES
--------------
python benchmark_sampling.py
python benchmark_sampling.py --n 30 --seed 42
python benchmark_sampling.py --dims rec_len pep_len


===========================================================================
NOTES
===========================================================================
- scrape_pdb_bind scripts run from scrape_pdb_bind/scripts/
- gen_sample scripts run from gen_sample/scripts/
- Conda environment: conda activate peppro
- DSSP requires mkdssp binary and CCD dictionary files in:
    /opt/miniconda3/envs/peppro/var/cache/libcifpp/
  (components.cif, mmcif_pdbx.dic, mmcif_ma.dic — downloaded once)
- Large output files (CIFs, PDBs, plots) are not tracked by git.
- run_config.json records every parameter used for full reproducibility.
- --protonate does not strip existing hydrogens; only fills missing ones.
- Experimental pH is not considered; --ph applies uniformly to all structures.
- SS annotations: peptide_ss/_receptor_ss from deposited _struct_conf (may be NA for NMR);
  peptide_ss_dssp/receptor_ss_dssp from DSSP (covers all methods including NMR).
