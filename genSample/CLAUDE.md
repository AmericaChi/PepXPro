# genSample

Modular pipeline for filtering, sampling, and exporting peptide–protein benchmark datasets
from the outputs of `scrape`.

## Environment

```bash
conda activate pepxpro
```

`isolation-forest` and `cluster` sampling require `scikit-learn` (included in the env).
`--tm-score-receptor` requires `tmtools` — not on conda, install with:
```bash
python -m pip install tmtools
```

## Structure

```
genSample/
├── scripts/
│   ├── 01_gen_sample.py       # entry point (argparse)
│   ├── 00_plot_samplingMethods.py
│   └── 02_plot_sampleDist.py      # per-run distribution comparison plot
└── modules/
    ├── utils.py                # load_tsv, save_tsv, enrich_rows
    ├── filters.py              # quality filter functions + apply_quality_filters
    ├── sequence_redundancy.py   # CD-HIT (receptor) + Biopython pairwise (peptide)
    ├── structural_redundancy.py # TM-score receptor (tmtools)
    ├── sampling.py             # stratified, kennard-stone, kde, isolation-forest, cluster
    └── export.py               # write_sample, save_run_config, link_cifs
```

## Inputs

Reads from `scrape/`:
- `summary.tsv` — main input (pdb_id, receptor, peptide, dG_kcal_mol, binding_type)
- `filtered_systems.tsv` — required only for `--max-added` / `--max-receptor-added`
- `fixed_cif/` — source CIF files for `--link-cifs` / `--copy-cifs`

## Outputs

Each run writes to `genSample/outputs/run_XX/`:
- `sample.tsv` — selected entries
- `run_config.json` — all parameters used (filters, sampling method, seed, paths)
- `pool_quality.tsv` — entries after quality filters (saved by default; skip with `--no-save-pools`)
- `pool_redundancy.tsv` — entries after redundancy filters (saved by default)
- `cif/` or `pdb/` — symlinks or copies of selected structure files (optional)
- `plots/run_comparison.png` — generated by `02_plot_sampleDist.py`

## Running

Also reachable from the project root via `python pepxpro.py genSample gen ...` (mirrors every
flag below; see top-level `CLAUDE.md`). Direct invocation:

```bash
cd genSample/scripts

python 01_gen_sample.py --dry-run
python 01_gen_sample.py --sample 20
python 01_gen_sample.py --sample 20 --sampling kennard-stone --seed 42
python 01_gen_sample.py --sample 20 --sampling kde
python 01_gen_sample.py --no-sample
python 01_gen_sample.py --sample 20 --max-peptide 15 --link-cifs
python 01_gen_sample.py --sample 20 --min-dg -15 --max-dg -8 --binding-type kd
python 01_gen_sample.py --sample 20 --max-added 3 --max-receptor-added 5
python 01_gen_sample.py --sample 20 --exclude bad_ids.txt --copy-cifs
```

## Filters available

| Flag | Description |
|---|---|
| `--single-chain` | Receptor with exactly one chain (**default: on** — use `--no-single-chain` to include multi-chain) |
| `--min/max-receptor N` | Receptor residue count bounds |
| `--min/max-peptide N` | Peptide residue count bounds |
| `--min/max-dg F` | Binding affinity range (kcal/mol) |
| `--binding-type kd\|ki\|both` | Measurement type |
| `--max-added N` | Max residues PDBFixer added to peptide |
| `--max-receptor-added N` | Max residues PDBFixer added to receptor |
| `--exclude FILE` | Blacklist of pdb_ids (one per line) |

## Pipeline order

```
quality filters → redundancy filters → sampling
```

## Redundancy filtering

| Flag | Tool | Description |
|---|---|---|
| `--seq-id-receptor PRESET` | CD-HIT | Cluster receptors by sequence identity |
| `--seq-id-receptor-threshold F` | CD-HIT | Custom threshold (with `custom` preset) |
| `--seq-id-peptide PRESET` | Biopython pairwise | Cluster peptides by sequence identity |
| `--seq-id-peptide-threshold F` | Biopython pairwise | Custom threshold |

Presets: `strict` (receptor 40% / peptide 70%), `medium` (50% / 80%), `lenient` (70% / 90%), `custom`.
Requires `receptor_seq` and `peptide_seq` columns in summary.tsv (generated by scrape step 2+).

Planned: functional redundancy.

## Structural redundancy

| Flag | Description |
|---|---|
| `--tm-score-receptor F` | Receptor TM-score threshold (e.g. 0.5 = same fold). Requires `tmtools`. |

Pipeline order: `quality → seq redundancy → structural redundancy → sampling`

## Sampling methods

| Method | Dims | Description |
|---|---|---|
| `stratified` (default) | 1D or 2D | Quantile-bin grid. 1D: n bins. 2D: 6×6 grid. Default: dG × pep_len |
| `kennard-stone` | N-D | Maximizes minimum pairwise Euclidean distance in feature space |
| `kde` | 1D only | Inverse KDE density — favors tail/underrepresented affinity regions |
| `isolation-forest` | N-D | Weights by isolation forest anomaly score — favors outliers in N-D space |
| `cluster` | N-D | K-means (k=n); selects entry nearest each centroid — uniform coverage |

Requires `scikit-learn` for `isolation-forest` and `cluster`.

Use `--dims` to select dimensions:

| Dim | Source field | Notes |
|---|---|---|
| `dg` | `dG_kcal_mol` | Binding free energy |
| `pep_len` | `peptide` `:N` | Peptide length |
| `rec_len` | `receptor` `:N` | Receptor length |
| `n_rec_chains` | `receptor` chain part | Number of receptor chains |
| `pep_helix` | `peptide_pct_helix` | % helix (peptide, DSSP) |
| `pep_beta` | `peptide_pct_beta` | % beta (peptide, DSSP) |
| `pep_coil` | `peptide_pct_coil` | % coil (peptide, DSSP) |
| `rec_helix` | `receptor_pct_helix` | % helix (receptor, DSSP) |
| `rec_beta` | `receptor_pct_beta` | % beta (receptor, DSSP) |
| `rec_coil` | `receptor_pct_coil` | % coil (receptor, DSSP) |
| `n_contacts` | `n_contacts` | Peptide–receptor heavy-atom contacts (4.5 Å) |
| `n_hbonds` | `n_hbonds` | H-bond proxies N/O/S within 3.5 Å |
| `sasa_burial` | `pep_sasa_burial` | Fraction of peptide SASA buried upon complex formation |
| `binding_kd` | `binding_type` | 1=Kd, 0=Ki/IC50 |
| `resolution` | `resolution` | Crystal resolution (Å); NMR/NA → None |
| `ss_class` | `peptide_ss_class` | Ordinal SS class (helix/beta/coil/…) |
| `func_class` | `receptor_func_class` | Ordinal receptor class |

Default: `dg pep_len`. KDE always uses only the first dim.
`n_contacts` and `n_hbonds` require those columns in `summary.tsv` (from scrape step 2).
Plot labels include effective dimensionality: `stratified-2D`, `kde-1D`, `cluster-2D`, etc.
